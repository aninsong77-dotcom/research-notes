내연구노트 사용 방법

처음 시작할 때
저장 폴더 지정 — 앱을 처음 열면 PDF 파일을 저장할 폴더를 지정합니다. 한 번만 설정하면 이후에는 자동으로 연결됩니다.
AI 키 연결 — AI 자동 분석 기능을 쓰려면 API 키를 입력해야 합니다. 무료로 발급받을 수 있어요.
프로젝트 만들기 — 연구 주제별로 프로젝트를 만들어 논문을 분리해서 관리할 수 있습니다.
논문 추가하기
논문 추가 버튼을 누르면 입력창이 열립니다.
PDF 파일을 첨부하고, 논문 전체 텍스트를 복사해서 붙여넣은 뒤, AI 분석 버튼 하나만 누르면 제목·저자·연구방법·결과 등 항목들이 자동으로 채워집니다.
논문 읽으면서 정리하기
책상 화면에서 논문 카드를 펼쳐놓고 읽으면서 추가로 메모하거나 내용을 직접 수정할 수 있습니다. 논문에 등장하는 변인(독립·종속·매개 등)에 태그를 달아두면 나중에 찾기 편합니다. 읽다가 떠오른 아이디어도 바로 기록할 수 있어요.
기타 자료 저장
척도, 설문지, 참고 자료 등 논문 외의 자료도 따로 저장하고 필요할 때 꺼내 볼 수 있습니다.
연구모형 그리기
모형 스케치북에서 변인들을 도형으로 배치하고 화살표로 연결해 연구모형을 직접 그려볼 수 있습니다. 가설 번호도 선에 붙여서 한눈에 정리됩니다.
연구 프로포절 작성
수집한 논문과 정리한 내용을 바탕으로 간단한 연구 프로포절 초안을 만들어볼 수 있습니다.
참고문헌 자동 생성
논문 목록에서 참고문헌 탭을 열면 입력한 논문들이 자동으로 참고문헌 형식으로 정리됩니다. 논문 쓸 때 복사해서 바로 붙여넣으면 됩니다.
