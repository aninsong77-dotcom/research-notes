# 내 연구노트 📚

논문 정리·아이디어 메모·연구모형 스케치를 한곳에서 하는 **설치 불필요** 웹앱입니다.
브라우저(크롬/엣지)에서 주소만 열면 바로 쓸 수 있어요.

## 주요 기능
- **논문**: 서지정보 + 정밀 분석표, PDF 첨부, 빠른 인용
- **자료**: 척도·도서·웹자료 등 보관
- **참고문헌**: 인용 목록 자동 정리
- **모형스케치북**: 변인을 도형으로 그리고 화살표로 연결, **변인을 묶는 큰 원/박스**(크기 조절)
- **아이디어 저장소**: 자유 메모
- **검색**: 키워드만 / 전체단어(메모 포함) 토글
- **정리 보기**: 키워드·저자·주제·변인·연구방법별 묶어보기

## 데이터는 어디에 저장되나요?
- 입력한 내용은 **각자 본인 브라우저(이 컴퓨터)** 에만 저장됩니다. 서버로 전송되지 않아요.
- 사람마다 자기 데이터만 보이고 서로 섞이지 않습니다.
- **백업** 버튼으로 폴더(구글드라이브/원드라이브 폴더도 가능)에 파일로 백업할 수 있고,
  다른 기기에서는 **받음**으로 그 파일을 불러오면 됩니다.
- 사이드바 **내 데이터** 버튼에서 저장 위치 확인·삭제가 가능합니다.

## 사용 방법
크롬 또는 엣지에서 이 페이지 주소를 열면 끝입니다. 회원가입·로그인 없음.

> ⚠️ 중요한 자료는 가끔 **백업(보냄)** 으로 파일을 따로 저장해두세요.
> 브라우저 데이터를 직접 지우면 복구할 수 없습니다.
