
# 생각 정리 도구

| 화면 | 쓰임 |
|---|---|
| **모형스케치북** | 변인과 화살표로 연구모형 그리기. 도형 추가 → 드래그로 이동 → 우클릭으로 화살표 연결 → 더블클릭으로 이름. 논문에 입력한 변인이 자동으로 후보에 뜹니다 |
| **마인드맵** | 생각을 나뭇가지로 펼치기 |
| **아이디어/메모** | 자유 메모와 할 일. 카드를 끌어 자유롭게 배치 |
| **기타자료** | 척도·도서·웹자료·보고서 보관 (참고문헌 목록에는 안 나옵니다) |
