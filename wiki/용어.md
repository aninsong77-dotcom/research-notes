
# 용어

| 낱말 | 뜻 |
|---|---|
| **DOI** | 논문마다 붙은 고유번호(`10.1111/pops.12163` 같은 모양). 이 번호로 서지정보를 받아옵니다 |
| **발췌** | PDF에서 뽑아 오른쪽에 모아둔 문장 조각 |
| **변인** | 연구에서 다루는 개념(자기효능감, 학업성취 등). 관련 논문을 잇는 열쇠 |
| **프로포절** | 연구계획서 초안. 발췌를 보내 모읍니다 |
| **폴더 연결** | PDF를 복사하지 않고 내 폴더의 파일을 가리키는 방식 |
| **동기화** | PC와 웹이 같은 내용을 보게 맞추는 것 (로그인 필요) |
| **APA 7판** | 심리·교육 분야 표준 인용 양식 |
| **RISS** | 국내 학술자료 통합 검색 사이트. 「인용하기」 글을 붙여넣어 자동 입력할 수 있습니다 |
| **CrossRef** | DOI를 관리하는 국제 비영리 명부. 앱이 서지정보를 여기서 받아옵니다 |
