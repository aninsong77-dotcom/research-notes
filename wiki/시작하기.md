
# 시작하기

처음 한 번만 준비하면 그다음부터는 손댈 일이 없습니다.

## 어디서 여나

| | 주소 | 특징 |
|---|---|---|
| **웹** | `aninsong77-dotcom.github.io/research-notes` | 브라우저가 데이터를 보호해 줍니다. 권장 |
| **PC** | 내 컴퓨터의 `index.html` | 인터넷 없이도 열립니다 |

둘은 같은 앱이고, 로그인하면 내용이 연동됩니다.

## 처음 준비 다섯 가지

1. **로그인** — 사이드바 맨 아래 「로그인하고 동기화」
2. **논문 폴더 지정** — 논문을 처음 넣을 때 「📁 폴더에서 연결」 → 폴더 고르기. 바꾸려면 그 창의 「다른 폴더 지정」
3. **백업 폴더 지정** — 「백업」을 한 번 누르고 폴더 고르기. 이후 자동 저장
4. **AI 키** — 「AI 설정」에 Groq API 키 입력 (무료 발급)
5. **프로젝트** — 로고 아래 드롭다운. 주제별로 논문·메모·모형이 완전히 나뉩니다

> **크롬을 쓰세요.** 폴더 연결이 크롬에서만 제대로 동작합니다.
