# 참고문헌 파서 — 설계

> 전제: [규정.md](./규정.md) 확정. 이 문서는 그 규정을 코드로 어떻게 옮길지 정한다.
> **코드는 아직 안 짠다.** 이 설계에 사용자 승인이 나야 짠다.

## 왜 다시 짜는가

기존 방식(`apaTidyEntry`)은 완성된 문장을 정규식으로 더듬어 고쳤다. 논문 형태가 하나
다를 때마다 규칙을 하나 더 붙였고(부록·■ 글머리표·Erlbaum·호 뒤 쉼표 누락 등), 이 방식은
**끝이 없다**는 것이 사용자 지적이자 오늘 반복된 실제 경험이다.

## 파이프라인

```
붙여넣은/PDF 에서 읽은 한 줄
        │
        ▼
① 파서 (parseRefEntry)  ── 규정과 무관. 글자를 "칸"으로 나누기만 한다.
        │
        ▼
{ authors[], year, yearSuffix, title, source, volume, issue, pages,
  publisher, institution, degree, doi, url, itemType, lang, confidence }
        │
        ▼
② 조립기 (assembleRef)  ── 규정표를 보고 칸을 문장으로 다시 만든다.
        │            ▲
        │            │
        ▼         규정표 STYLE_APA / STYLE_KAPP(학회) / STYLE_SCHOOL(학교, 비움)
완성된 참고문헌 한 줄 (+ 강조 구간 정보)
```

**핵심 원칙**: 규정이 바뀌면 ②의 표만 바꾼다. ①은 절대 규정을 모른다.
지금처럼 "이 형태는 학위논문이니까 이렇게, 이건 신문기사니까 저렇게" 하는 판단은
**전부 ①에 있고, 조립은 표만 본다.**

---

## ① 파서 — parseRefEntry(text) → RefEntry

### 판별 순서 (실패하면 다음 방법)

문헌 한 줄에서 자료 유형을 정하는 것이 파서의 핵심 작업이다. 순서:

1. **저자·연도 블록 분리** — `(연도)` 위치를 기준으로 앞은 저자, 뒤는 본문
2. **저자 블록이 "성, 이니셜." 나열로 깔끔한가** → `authors[]` 배열로 분해, 아니면 원문 그대로 `authorsRaw` 에 담고 `confidence: 'low'`
3. **연도 뒤 첫 마침표까지가 제목** — 단, 마침표가 문장 안에 없으면(원문 오류) `confidence: 'low'`
4. **제목 뒤 나머지를 유형별 신호로 판별**:

| 신호 | 유형 |
|---|---|
| `학위논문` / `thesis` / `dissertation` 낱말 | `thesis` |
| 마지막이 `이름, 이름.` 형태로 끝남(발행지 없이 출판사만, 학회 규정) | `book` |
| `쪽수-쪽수` 패턴 + 그 앞에 숫자(권) | `journal` |
| 위 어디에도 안 맞음 | `unknown` — **손대지 않는다** |

5. **journal**일 때 세부 분해: `학술지명, 권(호), 쪽시작-쪽끝` 정규식으로 한 번에.
   호가 없는 논문(`31(2) 232-242` 처럼 쉼표 누락 등)도 허용 폭을 둔다.

### 반환값

```js
{
  itemType: 'journal' | 'thesis' | 'book' | 'chapter' | 'web' | 'unknown',
  lang: 'ko' | 'en',
  authors: ['홍길동', '김철수'] | null,
  authorsRaw: '원문 저자 부분',   // authors 분해 실패 시
  year: '2013', yearSuffix: '',
  title: '...',
  source: '학술지명 또는 출판사 또는 소속기관',
  volume: '25', issue: '2', pages: '309-330',
  degree: '석사학위논문' | '박사학위논문',
  doi: '10.xxxx/yyy' | null,
  url: '...' | null,
  confidence: 'high' | 'low',   // low 면 조립하지 않고 원문 그대로 둔다
  raw: '원문 전체',
}
```

**confidence: 'low'인 항목은 절대 조립하지 않는다.** 원문 그대로 두고 "직접 확인" 표시만
한다 — 이게 오늘 여러 번 실패한 "일단 손대고 보자"를 막는 장치다.

## ② 조립기 — assembleRef(entry, style) → { text, html }

`style` 은 규정표(아래) 하나를 받는다. 조립기는 `entry.itemType` 에 맞는 템플릿을
`style` 에서 찾아 칸을 끼워 넣기만 한다. **조건 분기(if 문)로 규정을 표현하지 않는다** —
템플릿 자체가 데이터이므로, 학교 양식이 생기면 새 템플릿 객체만 추가하면 된다.

### 템플릿 예시 (학회 규정을 표로 옮긴 것)

```js
const STYLE_KAPP = {  // 한국심리학회지 상담및심리치료
  order: { east: 'first', separator: 'mixed' },   // 동양어 먼저, 가나다→알파벳
  hangingIndent: { unit: 'char', value: 4 },        // 4칸
  pageDash: '-',                                     // 하이픈 (엔대시 아님)
  emphasis: { ko: 'font:맑은 고딕', en: 'italic' },  // 국문=고딕, 영문=기울임

  journal: {
    ko: (e) => tpl`${authorsKo(e)} (${e.year}${e.yearSuffix}). ${e.title}. ${EM}${e.source}, ${e.volume}${/EM}(${e.issue}), ${e.pages}.`,
    en: (e) => tpl`${authorsEn(e)} (${e.year}${e.yearSuffix}). ${e.title}. ${EM}${e.source}, ${e.volume}${/EM}(${e.issue}), ${e.pages}.`,
  },
  book: {
    ko: (e) => tpl`${authorsKo(e)} (${e.year}). ${EM}${e.title}${/EM}. ${e.source}.`,
    en: (e) => tpl`${authorsEn(e)} (${e.year}). ${EM}${e.title}${/EM}. ${e.source}.`,
  },
  thesis: {
    ko: (e) => tpl`${authorsKo(e)} (${e.year}). ${EM}${e.title}${/EM}. ${e.source} ${e.degree}.`,
  },
  // ... chapter, web 은 학회 규정에 명시 없어 APA 를 상속
};

const STYLE_APA = { /* APA 7 그대로, 위 표 F 대비표 참고 */ };
const STYLE_SCHOOL = null;  // 사용자가 채워 넣을 자리. null 이면 KAPP 로 대체
```

`tpl` 은 문자열과 HTML을 동시에 만드는 작은 헬퍼(문자열 조립 시 강조 구간 위치를 함께 기록).

## ③ 예외 처리 — "손 안 댐"이 실패가 아니라 기능이다

| 상황 | 처리 |
|---|---|
| `confidence: 'low'` | 원문 그대로. 「직접 확인」 딱지 |
| `itemType: 'unknown'` | 원문 그대로. 「자료 유형을 못 알아봄」 딱지 |
| `authors` 분해 실패 | 원문 저자 문자열 그대로 조립(형식은 맞추되 저자만 원문 유지) |
| 규정에 없는 유형(웹자료 등) | APA 로 대체 조립 + 「학회 규정 없음 — APA 적용」 딱지 |

**목표 수치**: "높은 신뢰도로 자동 조립" 비율을 실제 논문으로 재서 사용자에게 보고한다.
100%를 주장하지 않는다 — 몇 %가 "직접 확인"으로 빠지는지가 이 도구의 정직한 성능 지표다.

## 검증 계획 (완료를 말하기 전에 반드시 거친다)

1. **단위 시험**: 규정.md 의 학회 예시 문장 6개(이진희·Hackett·조성호·Kline·황선정 등)를
   파서 → 조립까지 통과시켜 **원문과 정확히 같은 결과**가 나오는지 확인
2. **실전 시험**: 오늘 다룬 두 논문(현다현 2022, 대구한의대 2018 학술지) 참고문헌 전체를
   돌려 `high`/`low` 비율과 `low` 로 빠진 항목을 실제로 눈으로 검토
3. **회귀 시험**: 오늘 고쳐온 실측 사례들(Vondracek 책 판별, White 호 쉼표 누락,
   Ames 마침표 누락 등)이 새 파서에서도 옳게 처리되는지
4. **한글 붙여넣기 시험 (사용자)**: 강조 구간에 글꼴 지정을 넣었을 때 실제로 문서에
   맑은 고딕/이탤릭이 들어가는지, 문서 다른 서식이 안 깨지는지 — **이건 제가 확인 못 함**

이 네 단계를 거쳐 수치로 보고한 뒤에야 "완료"라고 말한다.
